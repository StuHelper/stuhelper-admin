# stuhelper-admin

StuHelper 管理端基于 Vben Admin v5.7.0 的 web-antd 应用，使用 Ant Design Vue。工作台汇总有权查看的待办和系统状态，业务页面按当前部署能力和服务端授权提供管理操作。

系统管理的注销队列支持按状态、阻断原因和到期条件筛选，翻页沿用相同条件。信息查询可按同一类型预览最多 20 条线索，显示候选及各业务域的计数。

## 本地开发

需要 Node.js 24.22.1 和 pnpm 10.33.4。安装使用 `pnpm-lock.yaml` 固定依赖。

```bash
make setup
make check
make dev
```

默认监听 `http://127.0.0.1:5174`。开发和预览将同源 `/api` 代理到 `http://127.0.0.1:8080`，可用 `STUHELPER_API_TARGET` 指定其他本地后端。缺少应用的 `.env` 时，`make setup` 会从 `apps/web-antd/.env.example` 初始化。

布局、主题、表单适配和共享组件沿用 Vben 的工作区结构。上游 tag 与提交记录见 [vendor/vben.json](vendor/vben.json)，上游 MIT 许可见 [LICENSES/Vben-MIT.txt](LICENSES/Vben-MIT.txt)。

界面默认跟随系统外观，也可在顶栏切换。主题由 `apps/web-antd/src/styles/theme.css`、`preferences.ts` 和 `app.vue` 的 Ant Design token 配置，导航图标随应用打包。需要离线原型时，使用 `VITE_DEMO=1 make dev` 加载本地合成响应。

## 会话、学校与权限

顶栏登录通过后端跳转到独立 Casdoor SSO。默认请求只发往同源 API，使用 HttpOnly 会话 Cookie。写请求读取当前 CSRF 值，宿主也可通过 `bootstrap(namespace, fetcher)` 注入认证传输。

顶栏账号菜单可修改本人公开昵称、退出当前设备或退出全部设备。退出当前设备撤销本次 StuHelper 会话，退出全部设备撤销该账号的全部 StuHelper 会话。Casdoor 注销另由后端按会话契约尝试。

并发会话检查共用一个请求。遇到 502、503、504、网络故障或超时，下一次检查依次等待 1、2、4 秒，最多等待 8 秒。临时故障时保留已登录界面和有效输入，由用户或页面发起复查。服务端明确拒绝身份时清除会话。

社区页面以会话中的 `content_school_id` 为当前学校，通过目录读取学校信息，失败时提供重试。认证管理的学校选择框把完整标识码、五位代码、名称或别名交给服务端搜索，滚动到底部加载下一页。

前端使用 `/api/v1/system/capabilities` 控制账务、QQ 群、QQ 绑定、开放平台、云盘托管、贡献准入和信息查询入口。能力加载完成前，受控页面等待。能力关闭时，菜单隐藏，直接访问显示不可用页面。

能力读取失败时保留导航入口，由服务端逐次执行授权。空菜单组自动隐藏。资料售价和会员、退款等交易界面随对应账务能力启停。

## 工作台与审核

首页先展示待办，再展示系统状态。待办涵盖评价与资料待审、投递失败、新反馈、学生与教师认证待审、退款、开放平台待审应用和存储阻塞。权限不足的卡片隐藏，读取失败的计数显示未知并支持重试。

`/moderation/queue`、`/moderation/content` 和 `/moderation/policies` 分别用于审核、内容处置和规则配置。审核决定保存后显示等待执行，服务端确认 `applied` 后显示已执行。

学校可将追评配置为免审、先审后发或先发后审。需审核时按追评逐条处理，每条决定只影响当前任务对应的追评。

审核工作台支持类型和时间筛选、处置历史、版本差异、快捷原因和逐项批量结果。评价管理可按最新选课来源更正归属、认定或撤销优质内容。展示配置维护八语言评分文案。

`/moderation/feedback` 提供状态筛选、游标分页、处理人、内部备注和统一邮箱回复。邮件正文以纯文本显示，附件按需下载。列表 JSON 上限为 4 MiB，详情读写上限为 16 MiB，可容纳最多一百条回复的转义内容。

反馈草稿沿用开始编辑时的修订。确定拒绝后草稿可继续修改，结果未知时沿用原内容和幂等键重试。权限撤销后清空来信和草稿。

## 目录、认证与资料

`/catalog` 提供按学校查询课程与教师，并更正名称、简介、院系及课程分类。缺失学分可保持未知。版本冲突保留输入，加载当前版本后再由管理员确认保存。

`/catalog/imports` 与目录管理还提供合并预览、停用和规范化数据导入，未匹配教师主页可一键跳至目录检索（通过内存状态传递，不写入 URL）。导入在浏览器内读取文件，支持按变更状态筛选预览差异后携带令牌确认。

在「目录与教务」中打开「教师站点匹配」，可按名称、状态查找学校官网站点和目录教师，核对候选后绑定、标记不对应或撤销。查看两侧列表需要本校 `catalog.teacher-sites.read`，保存决定需要 `catalog.maintain`。

本校拥有 `catalog.maintain` 的管理员可在「主页白名单与人数」选择允许展示的采集字段并核对人数，在「教师主页资料」管理显示状态、覆盖值及替代头像，在「教师本人申请」复核原提案和头像后批准或驳回。

教师主页投诉由审核人员在「审核工作台」按内容类型筛选。处置前核对投诉和当前主页状态，再决定隐藏主页或驳回投诉。

`/verification` 管理学生材料审核、资格查询、撤销与删除申请、学校配置和异常任务。资格查询按需读取资料。证件、完整身份及原始字段读取由服务端分别授权。

`/verification/teachers` 按学校审核教师材料、查询和撤销资格。审批可选本校目录中的教师，候选由服务端搜索，补件须填写说明。

`/resources` 管理资料状态、售价与单独授权。`/resources/categories` 维护分类名称、字段、取值和默认分组，`/resources/directories` 维护多级目录。创建目录时，课程选择框按当前学校进行服务端搜索，滚动到底部加载下一页。

`/resources/reviews` 以及学生和教师认证审核支持常见图片和 15 MiB 内 PDF 的沙箱预览、常用原因和跨页连续审核。超限文件提示下载核查。

学生和教师审核抽屉只接受显式关闭操作，放弃未保存内容前会要求确认。存储操作和 QQ 解绑弹窗也禁用遮罩关闭，写入进行中或结果未知时锁住关闭入口。

页面可用 `useLeaveGuard` 为未保存输入或未确认写入提示导航、刷新和关闭页面。结果未知的写入按页面提示用原请求重试。

## 法律文件

平台管理员从「系统」进入「法律文件」或「法律文件变量」。管理接口确认权限后显示菜单。首次发布时，尚待同意条款的管理员也可以从 `/system/legal/documents` 建立草稿并发布。

文档列表按页读取版本，并查询每份文件的当前生效版本。打开草稿可编辑标题、生效日和 Markdown，插入变量，预览未保存的内容。预览使用服务端渲染结果，校验失败时显示对应的字段或变量。发布前核对预览并确认。

已发布版本保留发布时的正文。管理员可以复制为新草稿或归档。变量在 `/system/legal/variables` 维护，保存后可查看受影响的已发布版本。修订冲突时保留输入并读取最新修订，写入结果未知时只能重试原请求。

## 云盘与存储运营

`/storage` 显示平台额度、已用、预占、可写容量和授权截止时间。实例操作包括暂停新写、恢复、排空和撤销。新额度支持十进制 GB、TB 或字节，页面显示换算结果及最低允许值。

对象与失败任务各自按游标分页，每页最多 25 条。写入携带当前修订或代次及幂等键。未登录或无权限时清空已展示数据。超出 JavaScript 安全整数范围的容量数据会被拒绝。

`/storage/contributions` 展示脱敏贡献状态、用户请求、容量和退出迁移。收到用量记录时显示已用、可写容量和待迁移副本数。成功读取时间缺失时只省略时间。

贡献管理可以重试阻塞的原请求。其条件、期限、额度和撤权决定来自用户的原请求。`/storage/custody` 按独立权限查询脱敏申请并恢复用户已授权的操作。结果未知时沿用原修订和幂等键。

`/storage/admissions` 管理贡献账号、角色或分组在全局或指定实例的准入规则。准入级别、角色 ID 与分组 ID 使用可输入多个值的标签控件。保存携带读取时的修订，结果未知时重试原请求。

## 账务、QQ 与系统管理

`/billing/refunds` 审核充值退款并登记人工打款结果。收款资料按需读取，服务端要求单独权限和成功审计，关闭详情时清除。

`/billing/accounts` 查询余额、订单与明细，处理积分购买退款、奖励发放与撤销，并记忆当次会话最近查询的签发方。信息查询、退款详情与审计可按启用能力在内存中预填账号，跳到账务、QQ 绑定、角色授权或会话下线。

`/billing/memberships` 维护套餐、价格、期限和资料覆盖范围。目录精确匹配，不含子目录。缺少覆盖规则的套餐无法购买。停售停止新购买和续费，已购权益按原期限有效。保存使用当前版本或修订。

管理员撤销奖励时可勾选“恢复本次奖励占用的周期配额”。该项默认关闭，提交成功或切换账号后清空。会员方案列表按游标加载后续页。

`/billing/config` 维护支付渠道、积分方案和奖励规则。仅启用账本时，显示积分与奖励配置。

`/qq-binding` 按账号查看 OneBot、QQ 互联和官方机器人三项状态，只展示脱敏 QQ 号。管理员解除指定项时填写原因并提交当前修订。其余项独立保留，结果未知时使用原请求重试。

`/system/eligibility` 分别显示全站默认和本校生效规则。购买资料、购买会员与下载资料独立配置。保存携带已读版本，服务端拒绝覆盖并发修改。

`/system/sessions` 供平台管理员设置会话复核间隔和故障宽限，并在确认目标账号后强制下线。两项默认均为 30 分钟，范围分别为 5 至 240 分钟和 0 至 240 分钟。冲突或故障时保留输入。

`/system/closures` 展示业务档案编号、注销状态、冷静期截止时间、各清理步骤和阻塞原因。七天冷静期内，申请人可撤销，管理端禁用继续处理。冷静期后，管理员可对阻塞申请重试。撤权后清空列表和详情。

## 教师官网刷新（2026-11-15）

教师官网刷新页面位于 /catalog/teacher-sites，使用 catalog OpenAPI 0.6.0（catalog v0.1.9）生成快照。页面显示当前教师标记人数（显示的教师、有授课记录、官网唯一匹配、两者都有）、最近一次刷新的类型、触发方式、状态、耗时、请求数和官网主页数，以及未匹配的官网主页。

定时刷新每月一次，类型为增量。全量刷新只能在本页手动开始，开始前需要确认。手动请求带幂等键；已有刷新正在进行时服务端返回冲突，页面提示等待，并在刷新排队或进行时每五秒读取一次状态。

未匹配清单按原因筛选、按游标分页，只显示官网姓名、官网单位、原因和候选数，不显示工号或联系方式。接口同时检查学校范围，查看和触发由服务端记录审计。

| 场景 | 预期结果 |
| --- | --- |
| TEACHER-SITES-01 | 显示标记人数、最近刷新和未匹配清单，请求不含工号和联系方式字段 |
| TEACHER-SITES-02 | 手动增量刷新带幂等键，正在进行时按钮禁用，冲突时提示等待 |

## 国际化

默认简体中文，另有英文、法文、俄文、日文、韩文、西班牙文和阿拉伯文。应用消息位于 `apps/web-antd/src/locales/langs`，Vben 共享消息位于 `packages/locales/src/langs`。

新增可见文案和可访问名称使用翻译键，为八种语言提供一致的键与占位参数。复数按语言规则写全分支，数字、金额、日期和容量使用公共格式化接口。默认时区为 `Asia/Shanghai`，阿拉伯语页面及组件使用 RTL。

页面启动时优先采用有效的 `?lang=` 参数，其次使用本地偏好，默认简体中文。顶栏切换会加载新文案和组件语言并更新偏好，当前页面的草稿和未确认写入保留。语言查询参数存在时，刷新仍按参数初始化。

同形词例外在统一语言策略中登记具体键、值和原因。本仓的 `locale-policy.yaml` 与 `locale-policy.json` 保存消费方快照。翻译以源语言语义和实际交互为准。详见[国际化规格](https://github.com/StuHelper/stuhelper/blob/develop/docs/spec/internationalization.md)。

## 契约与检查

`make generate` 从 `contracts/` 中的提供方 OpenAPI 生成 TypeScript 类型。`contracts/*.source.json` 记录来源版本、提交、摘要与文件映射。提供方与消费方的组合兼容性由架构仓库核对。

`make check` 执行仓库和工作流检查、契约摘要与生成结果校验、八语言检查、类型检查、ESLint、Vitest 和生产构建。文档检查可单独运行 `pnpm run check:docs`，国际化检查可单独运行 `pnpm run check:i18n`。

浏览器套件使用 Playwright 1.64.1，配置八种语言的桌面和移动 Chromium。首次使用时先安装 Chromium，再构建并运行测试。

```bash
pnpm exec playwright install --with-deps chromium
make build
make browser
```

指定模块可用 `make browser MODULE=storage-admissions`，也可通过 `ARGS` 传入 Playwright 参数。`make storage-browser` 是完整浏览器套件的兼容入口。合成 HTTP 夹具位于 `tests/e2e`，测试输出写入 `.tools/playwright-results`。

[模块清单](module.json)的 `scenario_tests` 按规格编号登记实际测试文件和用例名。

| 主题 | 测试证据 |

## 教师图片的媒体域名

在「教师主页资料 → 教师主页图片」中打开预览，可查看该账号当前能读取的头像和正文图片。在「教师本人申请」中打开申请详情，可预览申请人提交的头像。

浏览器从同源 Catalog 图片接口读取头像和正文图片。Catalog 可直接返回图片，也可跳转到 `https://media.stuhelper.com`。媒体域名须允许页面来源的跨域读取。

本地 Vite 开发或预发布构建可设置 `VITE_MEDIA_ORIGIN` 为完整 HTTPS 来源，例如 `https://media.staging.example.org`。构建容器时通过同名 `--build-arg` 传入，构建阶段同时写入客户端和 Nginx 的 `connect-src`。单独部署静态文件时，在站点的 CSP 中允许同一来源。
