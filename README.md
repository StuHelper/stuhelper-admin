# stuhelper-admin

基于 **Vben Admin v5.7.0 官方默认 web-antd 应用**的 StuHelper 管理端，组件库为 Ant Design Vue。当前提供平台状态、课程教师目录、评价审核、存储运营、托管、贡献和资料管理。页面复用宿主认证传输，业务权限由服务端执行。

## 本地开发

需要 Node.js 24.22.1 和 pnpm 10.33.4。make setup 使用 pnpm-lock.yaml 安装固定依赖，CI 通过 packageManager 字段读取 pnpm 版本。

```bash
make setup
make check
make dev
```

默认监听 127.0.0.1:5174，API 代理为 127.0.0.1:8080，通过 STUHELPER_API_TARGET 配置。setup 只在缺失时复制 .env.example 为被 Git 忽略的 .env，不覆盖已有文件。

## 上游与本地改动

来源 tag 和精确提交记录在 vendor/vben.json，上游 MIT 许可证保存在 LICENSES/Vben-MIT.txt。内部 packages、internal 与 pnpm workspace 保留 Vben 的共享组件组织方式，业务仓库仍按 StuHelper 的多仓库边界维护。

仅保留 web-antd 应用，移除其他 UI 应用、演示页面、Mock 后端和上游统计脚本。保留官方布局、主题、表单适配、国际化和共享组件。主应用不伪造用户、角色、通知或业务统计。

为了修复实际安装检查中的兼容问题，构建工具固定 tsdown/@tsdown/css 0.23.2 和 vite-plugin-vue-devtools 8.2.1。原 skipNodeModulesBundle 配置使用当前 neverBundle 选项表达，继续生成并检查类型声明。同时固定兼容 Vite 8 的 inspect 依赖和 unplugin-dts 1.1.2。移除未使用的 Git hook 自动安装依赖。完整工具链通过 pnpm-lock.yaml 固定。

## 身份和权限边界

框架首页不展示业务数据。/storage 和 /contributions 页面只在受保护的服务端 API 返回成功后显示脱敏账本。未登录或权限不足时展示明确错误并清空旧数据，不使用本地角色、演示账号或手工 token 绕过服务端授权。

请求复用同源认证传输。宿主可通过 bootstrap(namespace, authenticatedFetch) 注入当前认证请求；存储、托管和贡献页面共用该传输。默认入口使用同源 fetch，未认证时显示未登录或不可用。实际网页登录和 Next SSO 另行集成。

authenticatedFetch 每次读取宿主当前凭据，保留取消信号、幂等键和同源限制。页面不缓存令牌。hostTransport.test.ts 验证托管与贡献请求使用同一宿主传输、凭据轮换和认证失效后的私有数据清空。

公开框架页与管理页面使用同一布局。管理页面访问 `/api/v1/reviews/admin`、moderation 和 catalog 接口，服务端逐次检查学校权限。认证失败时清除旧结果，不能通过页面路由或本地 accessToken 取得权限。

当前不提供本地账号密码登录、演示账号或 OAuth client secret。后续统一登录通过独立官方 SSO 接入。

## 业务入口

`/academic/reviews` 提供待审与申请队列、内容管理及审核规则。管理员可以查看原文、隐藏、恢复、删除、修改正文和讨论身份。决定保存后显示等待执行，只有服务端确认 applied 才展示已执行。

`/academic/catalog` 提供按学校查询课程与教师，并更正名称、简介、院系及课程分类。缺失学分可保持未知。版本冲突保留输入，加载当前版本后再由管理员确认保存。

目录管理还提供合并预览、停用和规范化数据导入。导入在浏览器内读取文件，预览差异后携带令牌确认。目标资料在合并后继续使用，源记录的旧链接及历史保留。

审核工作台支持内容类型与时间筛选、同一内容的处理记录和版本、处置复核、批量预览与逐项结果。管理员可依据最新选课来源更正评价归属，认定或撤销优质内容。展示配置维护预览长度与八语言评分文案。

## 契约与检查

platform、storage 和 contribution 接口分别从提供方 OpenAPI 生成类型。contracts 中的 source.json 记录提供方提交、版本、摘要与映射，make check 验证存储生成结果。存储共享样例来自提供方，客户端校验时间、整数范围、分页上限和响应字段。

make check 执行八语言覆盖检查、类型检查、应用 lint、单元测试与生产构建。中文为默认语言，支持英文、法文、俄文、日文、韩文、西班牙文和阿拉伯文。金额、数字、日期与复数由统一格式接口处理，阿拉伯文布局使用 RTL。存储浏览器检查使用明确 HTTP 夹具覆盖八语言、桌面和移动布局、键盘确认、未知结果重试、分页及撤权清空。真实身份与供应商联调另行验收。

contracts/platform.openapi.yaml 与生成类型来自 platform 仓库。scripts/contracts 独立固定接口生成工具使用的 TypeScript 5，不改变 Vben 应用的 TypeScript 6 工具链。`contracts/platform.source.json` 记录契约来源。课程、评价与审核的 OpenAPI 和生成类型同样记录来源、提交和摘要，并检查生成一致性。工作区检查核对来源提交及提供方兼容性。

make check 执行八语言覆盖检查、类型检查、应用 lint、单元测试与生产构建。中文为默认语言，支持英文、法文、俄文、日文、韩文、西班牙文和阿拉伯文。金额、数字、日期与复数由统一格式接口处理，阿拉伯文布局使用 RTL。学生端和管理端的 352 项八语言桌面与移动浏览器检查在架构仓库维护，使用合成响应。真实登录与生产运行分别验收。

架构与业务规格见 [StuHelper Next](https://github.com/StuHelper/stuhelper-next)。

## 存储运营管理

实例页展示平台额度、已用、预占、可写容量和授权截止时间，支持暂停新写、恢复暂停、排空、撤销与额度调整。页面按状态提供操作提示，实际资格和权限由服务端判定。撤销后重新授权不由恢复按钮处理。

对象与失败任务分别按游标分页，每页最多 25 条。确认操作携带当前修订或代次与幂等键。网络失败或响应不确定时保留原请求，只能重试原请求；未登录或无权限立即清除已展示业务数据。容量等整数超出 JavaScript 安全整数范围时拒绝展示，避免静默舍入。

运行 make build 后执行 make storage-browser。Playwright 固定为 1.64.1，以支持 Ubuntu 26.04，首次运行先执行 pnpm exec playwright install --with-deps chromium。浏览器夹具仅存在于 tests/e2e，不打包进应用，也不连接真实存储账号。

## 存储贡献管理

/contributions 使用独立管理权限查看脱敏贡献状态、用户请求、容量、授权失败和退出迁移。管理员只能重试阻塞的原请求，不能借重试修改用户同意、期限、额度或撤权决定。普通贡献权限和后台服务身份不能使用管理接口。

提供方维护贡献浏览器 SDK，快照校验覆盖源码摘要和生成类型。make storage-browser 同时执行存储与贡献页面的八语言、桌面/移动检查，验证未知结果原键重试、分页和权限撤销。测试使用显式 HTTP 夹具，不开放真实贡献。

贡献截图按需存放在 CONTRIBUTION_SCREENSHOTS 指定的任务目录，默认关闭；每轮最多 16 张、总计不超过 20 MiB，人工检查后删除。浏览器 test-results 仅保留本机本轮报告，任务结束清理，不上传 CI 制品或扩大缓存。

## 存储托管管理

/storage-accounts 使用独立读取和恢复权限查看脱敏申请。管理员可以恢复用户已同意的原操作，不接收账号密码，也不能替用户修改托管期限、同意版本、贡献条件或准入。

操作保存原申请标识与修订，响应丢失时只重试原恢复操作。权限撤销立即清空私有列表，加载、空数据、拒绝和网络失败均有明确展示。托管接口及浏览器 SDK 由 storage 提供并验证快照摘要。

八语言、桌面与移动浏览器检查覆盖键盘恢复、未知结果重试、未登录和撤权。测试全部使用隔离 HTTP 夹具，实际应用登录、真实账号及生产接入另行验收。

托管页面截图使用 CUSTODY_SCREENSHOTS 指定的任务目录，默认关闭。人工检查只选中文桌面和阿拉伯语移动视口，两端总计最多四张、8 MiB，检查后删除。

## 学习资料

/resources 提供统一分类、配置字段筛选及分组、课程资料入口和目录下载包。分类字段来自服务端，页面不按课件或往年题名称分支。分组范围为当前分页，未知字段保持为空。

上传使用当前条款、允许类型和大小，保留原文件名。资料元数据保存、文件传输、关联与提交审核分别显示结果，网络失败重试原幂等请求。文件写入结果不明时先查会话，取消只有服务端确认后才显示完成。

本人资料可更正并提交新版本，旧发布版继续可用。申请列表与详情读取持久化回执和当前审核状态。目录打包只列可访问文件，展示全部分包，允许单包重试。

接口复用宿主认证传输，逐次取得当前凭据。当前权限拒绝后清空受保护数据。resources 与 media 的契约快照保留提供方提交、文件映射和摘要，生成结果由固定版本工具检查。

本轮新增八项传输与配置单元测试，以及八语言、桌面与移动视口的 64 项资料浏览器用例。测试使用明确 HTTP 夹具；实际文件链路由私有 backend 的独立 PostgreSQL 集成测试验证。真实登录和生产接入另行验收。

管理页面另提供分类名称、字段类型、整数范围、选项、默认分组、目录、单独授权、状态变更和资料审核。审核员可通过独立权限下载待审原文件，决定登记后继续查询执行结果。

资料上传启用本人文件复用。匹配已有同用途、同保护要求的内容时，页面提示免重复上传，新资料仍需独立审核。复用尚在处理时保留原会话并查询结果，不重复发送文件字节。
